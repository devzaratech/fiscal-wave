# Internationalisation / Internacionalización

**EN:** Supported application locales in the first release: `es-CL` and `en` (specify en-US or en-GB before launch). Default for Chilean taxpayer journeys: `es-CL`. Translation catalogs should be structured by domain: `common`, `invoices`, `partners`, `operations`, `admin`. Keep keys stable and typed. Add a missing-translation CI check. Ensure accessible labels, errors, validation messages and e-mails are localised. Browser locale is a preference, never an authority for tax calculations, legal identifiers or XML schemas.

**ES:** Idiomas de primera versión: `es-CL` e `en` (decidir en-US o en-GB antes del lanzamiento). Para Chile, predeterminar `es-CL`. Catálogos por dominio y claves estables. CI debe detectar traducciones faltantes. Traducir labels accesibles, errores, validaciones y correos. La preferencia de navegador no cambia impuestos, IDs ni esquemas tributarios.

## Acceptance / Aceptación
- [ ] Locale switch persists per user; no cross-tenant leak / El idioma persiste sin filtrar datos.
- [ ] Numbers, currency, timezone and date formatting have locale-specific tests / Formatos regionales probados.
- [ ] Both language catalogs contain the same keys / Catálogos completos.
- [ ] SII codes and signed XML remain as mandated by the competent authority / Sin traducir XML oficial.
- [ ] Bilingual docs reviewed in the same PR / Documentación EN/ES revisada en un PR.
