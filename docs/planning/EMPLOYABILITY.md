# Employment skill map / Mapa de empleabilidad

**EN:** This is a training map inferred from Chilean job adverts consulted during Nov 2026; it is **not** a guarantee of hiring, and job availability changes. **ES:** guía de estudio basada en avisos consultados en noviembre de 2026; no asegura contratación ni vacantes vigentes.

| Job family / Perfil | Demonstrable skill / Competencia | FiscalWave evidence / Evidencia |
|---|---|---|
| Backend Java / Java backend | Java 17+/21/25, Spring Boot, SQL, REST, JUnit, Maven | DTE model, Postgres transactions, tested API |
| Full-stack / Full stack | React, TypeScript, forms, state, accessibility, REST | Shell + invoice microfrontend, bilingual UX |
| Distributed systems / Distribuidos | DDD, hexagonal, Outbox, Kafka/SQS, idempotency, circuit breaker | Delivery state machine, reliable consumer and contract tests |
| Cloud / DevOps | IAM, VPC, EC2, ECS, S3, Lambda, RDS, SQS, ALB, Terraform | Limited AWS lab; health checks + teardown and invoice review |
| Security / Seguridad | OAuth2/OIDC, IAM, secrets, tenant isolation, OWASP | Adversarial auth tests, safe secrets architecture |
| QA / SDET | JUnit, Mockito, Testcontainers, CI, E2E, test design | Automated regression and failures |
| Design / Diseño | C4/PlantUML, tradeoffs, HA, RPO/RTO, observability | ADR + 5-minute system explanation |
| AI-assisted engineering / Ingeniería asistida por IA | Human-owned architecture, context preparation, prompt contracts, model selection, automated evaluation, versioned handoff, privacy controls | FW-032 decisions, tested PRs, CI results and candid tradeoff explanations; no claim of ML training or formal AI qualification |
