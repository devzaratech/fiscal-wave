# Original interview practice / Práctica técnica original

**EN:** This folder is an independent training kit, **not code from employer tests**. The goal is to write working solutions and explain them in interviews, in English and Spanish. Timed sessions, test-first, complexity analysis and a review note. **ES:** ejercicios originales, no respuestas de pruebas privadas; resolver, probar y explicar.

## Starter tasks / Primeros retos
- [EX-01 Java duplicate invoice keys](challenges/EX-01-java-dedup.md) — HashMap, composite keys, complexity / Mapas y claves compuestas.
- [EX-04 SQL monthly paid ranking](challenges/EX-04-sql-monthly.md) — joins, grouped data, rank / SQL analítico.
- [EX-08 System design delivery](challenges/EX-08-distributed-delivery.md) — event guarantees, outbox, observability / Diseño de sistemas.
- [Synthetic SQL seed](sql/fixtures.sql) — **not production data** / Datos sintéticos.
- [Learning log / Registro](PROGRESS.md) — copy a row per session; never pretend incomplete exercises are completed.

## Session protocol / Protocolo
1. Read the original prompt; no generative solution assistance while timing yourself if simulating a restricted test.
2. Write assumptions and input/output; solve in Java/SQL/TypeScript.
3. Execute tests, edge cases and a complexity check.
4. Explain your reasoning aloud for 60–90 seconds in **EN and ES**.
5. Record result, gap and next practice. No fabricated performance metrics.
